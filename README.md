# Sigmarix Quests

Квестовая система для Minecraft 1.7.10, Forge 10.13.4.1614 и Java 8.
Репозиторий: https://github.com/vvmax/SigmarixQuests.

## Исходники и документация

[Sigmarix Quests для Forge 1.7.10](quests1710/README.md) — независимая квестовая система.
[Матрица соответствия FTB Quests](quests1710/COMPATIBILITY.md) перечисляет реализованные функции и оставшиеся отличия.

[Отдельная русская книга для шести модов](quest-packs/ru-six-mods-1.7.10) содержит
180 квестов и отдельный ресурспак иллюстраций; в JAR мода они не включены.

[Русская экспертная кампания Sigma](quest-packs/ru-expert-sigma-1.7.10) содержит
696 квестов в 46 разделах с межмодовыми зависимостями под изменённые рецепты.
Для её полной загрузки требуется версия мода 0.27; книга поставляется отдельно.

Источники включённых в мод сторонних ресурсов перечислены в
[THIRD_PARTY_ASSETS.md](quests1710/THIRD_PARTY_ASSETS.md).

Последние исправления добавляют видимую кнопку «Команды» в книге и передачу
сохранений и синхронизации частями по 30 КБ, чтобы не превышать сетевой лимит
Minecraft 1.7.10. Версия 0.27 поддерживает книги до 16 МиБ UTF-8 JSON.
