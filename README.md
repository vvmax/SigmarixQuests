# Sigmarix

Проект разработки модов Forge и Bukkit-плагинов для Minecraft 1.7.10 под Crucible.

## Работа в Codex Cloud

Выбирайте репозиторий `vvmax/Sigmarix` при настройке облачной среды.
После подготовки и проверки инструментов опубликуйте среду и запускайте в ней задачи разработки.

Результаты задач сохраняйте в отдельные ветки GitHub и оформляйте Pull Request с описанием изменений и выполненных проверок.
