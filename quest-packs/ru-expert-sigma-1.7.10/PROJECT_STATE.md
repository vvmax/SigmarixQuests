# Состояние кампании

24.10.2026: подготовлена версия 1.0.0 для Sigma и Sigmarix Quests 0.27.0-SNAPSHOT (`a4a9d16`). 696 квестов в 46 тематических разделах, 7 верхних групп; 940 задач без `check`.

Файлы формата 2 находятся в `config/sigmarixquests`, авторские определения — в `authoring`. `manifest.json` содержит SHA-256 устанавливаемых файлов; `quest-index.csv` позволяет найти задание по ID. Снимки реестра и плана изменённых рецептов находятся в `evidence`.

Включён отдельный регрессионный тест `QuestLargeBookTest`. Восемь целевых нативных тестов прошли на коде 0.27; см. `docs/VALIDATION.md`. Полный игровой прогон и установка на живой сервер не выполнялись.

Собственный временный патч лимитов не включён: использовано опубликованное автором обновление 0.27. Оно передаёт книгу целиком частями, а не выбранную главу. Лимитов для текущей кампании достаточно.

Дальнейшие изменения: сохранять существующие ID, обновлять определения в `authoring`, запускать генератор и аудит, затем нативные тесты. Не редактировать только итоговый JSON: следующая генерация его перезапишет. Для развития CustomNPCs нужны реальные серверные ID контента. Для небольших косметических дополнений и редких взаимодействий покрытие обзорное, что отмечено в `docs/COVERAGE.md`.
