# Состояние кампании

24.10.2026: подготовлена версия 1.1.0 для Sigma и Sigmarix Quests 0.28.0-SNAPSHOT (`d6a27d3`). 696 квестов в 46 разделах, 7 групп; 940 задач без `check`. Все зависимости пересмотрены; глубина 23 вместо 61, стабильные ID. Награды — 48 очков XP за книгу. Добавлены 23 подробные страницы, восемь игровых снимков и схема IC2 в клиентском ресурс-паке.

Файлы формата 2 находятся в `config/sigmarixquests`, авторские определения — в `authoring`. `manifest.json` содержит SHA-256 устанавливаемых файлов; `quest-index.csv` позволяет найти задание по ID. Снимки реестра и плана изменённых рецептов находятся в `evidence`.

Включён регрессионный тест `QuestLargeBookTest`. Шестнадцать нативных тестов прошли на коде 0.28; см. `docs/VALIDATION.md`. Изолированный игровой стенд подтвердил уровни алтарей II–VI и отрисовку двух карт и двух иллюстрированных страниц. Компоненты учебного реактора IC2 прошли 20 000 циклов без нагрева корпуса. Полное прохождение и установка на живой сервер не выполнялись.

Собственный временный патч лимитов не включён: использовано опубликованное автором обновление 0.28. Первое подключение передаёт полную книгу, последующие изменения — дельты. Проверены изменение одного квеста и восстановление основы. Лимитов для кампании достаточно.

Дальнейшие изменения: сохранять существующие ID, обновлять определения в `authoring`, запускать генератор и аудит, затем нативные тесты. Не редактировать только итоговый JSON: следующая генерация его перезапишет. Для развития CustomNPCs нужны реальные серверные ID контента. Для небольших косметических дополнений и редких взаимодействий покрытие обзорное, что отмечено в `docs/COVERAGE.md`.
