# Состояние соответствия FTB Quests 1.12.2

Целевая точка сравнения: публичная ветка `FTBTeam/FTB-Quests:1.12`, commit
`85b7652bd69f3bc4c03ba9ba24909ddea0605a53`. Этот файл отделяет реализованное
поведение от ещё не перенесённого. Названия типов ниже — аналоги, а не гарантия
бинарной/форматной совместимости. Полное требование «все функции» пока не закрыто.

## Блоки и интеграции

Десять устройств: task/progress screen, barrier, reward collector, redstone/player
 detector, loot crate opener, quest chest, crate storage, progress detector.
Экраны собираются в прямоугольники до 8×8 из обычных экранных блоков, части
используют привязку основного блока; есть рендерер в мире, GUI конфигурации,
синхронизация и остановка при разрушении основного блока. Прогон проверяет 2×2.
Квестовый сундук имеет 27 слотов и сдаёт расходуемые предметы в активные задачи;
хранилище кейсов имеет 54 физических слота, без виртуальной вместимости оригинала.
Детектор имеет цифровой/аналоговый режим. Для расходования ресурсов автоматикой
нужен онлайн-владелец. Некоторые настройки, текстуры и декоративные предметы
оригинала по-прежнему отличаются.

Прямые интеграции: IC2 Experimental 2.2.828, обычная Botania r1.8-249 / Baubles
1.0.1.10, ProjectE PE1.10.1, CustomNPCs 1.7.10d, BuildCraft 7.1.23, NEI 1.0.5.120
с официальными CodeChickenCore/Lib. Проверены настоящие сущности/контроллеры,
EnergyNet, двигатель RF, кошелёк, письма с вложениями и NEI GUI. API и тестовые
JAR не включены в production JAR. Baubles используется обычной Botania; отдельной
Baubles-интеграции в выбранной исходной ветке FTB Quests нет.

Возможности отсутствующих на 1.7.10 API имеют независимые аналоги: стадии
GameStages, уровни Reskillable, события/серверные JavaScript KubeJS, режимы книг
PackMode, таблица прогресса FTB Utilities, рецепты/использования/лут JEI через NEI.
Это не бинарная совместимость с модами 1.12 и не исполнение исходных скриптов без
изменений. JavaScript выполняется на Java 8 Nashorn; ошибка reload сохраняет
предыдущие обработчики. Состояние разных режимов не смешивается; команды общие.
Добавлены аварийные предметы с личным таймером и взвешенное выпадение кейсов из
существ. Импортируются их настройки, NPC-задачи/награды, стадии и уровни.

## Проверки

- JUnit для схемы, NBT, групп и безопасного сетевого кодека.
- Forge fixture с настоящими реестрами и подставленными игроками/мирами:
  списание/резервирование ресурсов, XP, NBT, RF/жидкости, посещения, награды и т.д.
- Реальный Forge-клиент: книга и редактор отрисованы без CoFH.
- Встроенный сервер: handshake, выполнение, выдача/запрет повторной награды,
  синхронизация инвентаря, сохранение редактором, отказ устаревшей правке,
  перезапуск мира и сохранение прогресса.
- Python-тесты конвертера, двоичного NBT, UUID миграции, режимов/альтернатив и таблиц.
- Версия 0.4: Forge читает реальный NBT-файл Python-мигратора и JSON-конвертера;
  составные фильтры проверяются на настоящих реестрах. Реальный клиент/встроенный
  сервер проверяет сохранение формы, руководство/toast, контейнер и привязку
  устройства, отдельные подтверждения и task dependency.

Проверены отдельный запуск без дополнительных модов и совместный запуск всех
перечисленных интеграций. Удалённый dedicated server, Crucible, другие моды и все сочетания
настроек не проверены. Наличие этой таблицы и успешной сборки не означает полного
соответствия оригиналу.
