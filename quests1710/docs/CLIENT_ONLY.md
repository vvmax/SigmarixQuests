# Клиентская сборка 0.28.1

Файл `quests1710-0.28.1-SNAPSHOT-client.jar` заменяет обычный JAR только на клиенте,
подключающемся к серверу. На сервере используется опубликованный полный JAR
`quests1710-0.28.1-SNAPSHOT.jar`; переустанавливать его не требуется.
Не устанавливайте оба JAR одновременно. Для квестов в одиночной игре используйте полный JAR.

Клиентский JAR содержит интерфейс, редактор, сетевые сообщения и сборку дельт,
общие схемы книги, проверку вводимых данных, текстуры, звуки, регистрацию блоков
и предметов, получение NBT устройств и локальное предсказание инвентаря.
Рецепты сохранены для клиентского просмотра. Необязательные интерфейсы Botania,
IC2 и RF читают только полученные от сервера данные; ввод ресурсов не зачисляется
на клиенте. Серверные предикаты пользовательских фильтров на клиенте не исполняются.

В нём нет загрузки серверной книги/профилей, хранения прогресса мира, серверных
скриптов, расчёта выполнения квестов, выдачи наград, выполнения серверных команд,
автоматизации устройств, виртуального банка ящиков или серверных обработчиков
запросов. `QuestService` оставлен только как совместимое имя общих JSON/NBT и
предметных утилит для интерфейса; экземпляра серверного сервиса в сборке нет.
В одиночной игре мод молча неактивен: он не блокирует меню или загрузку мира,
не открывает книгу и не отправляет квестовые запросы встроенному серверу.

## Сборка

В настроенной среде проекта:

```sh
mc-gradle -p quests1710 clientOnlyJar verifyClientOnlyJar
```

Пакетировщик читает SRG-байткод, заменяет загрузчик и состояния устройств
клиентскими реализациями, удаляет серверные точки входа и оставляет код,
достижимый из клиентских интерфейсов и нужных Minecraft/Forge callbacks.
Общие типы и конструкторы сохраняются для Gson и регистрации объектов.
Проверка запрещает ссылки на `EntityPlayerMP`, `MinecraftServer`, серверный
прогресс и скрипты. Отдельно проверяются ссылки на методы и поля после обычного
преобразования SRG→MCP для среды разработки. Средства пакетирования, тестовые
моды и compile-only API в распространяемый JAR не попадают.

## Проверка соединения

```sh
mc-gradle -p quests1710 prepareClientOnlySmoke \
  -PclientSmokeHostJar=/path/to/original/quests1710-0.28.1-SNAPSHOT.jar
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=true LP_NUM_THREADS=2 ALSOFT_DRIVERS=null \
  python3 quests1710/tools/run_client_only_smoke.py
```

Тест запускает два изолированных процесса Minecraft с разными папками и без
классов основного мода в classpath. Полный JAR открывает тестовый мир по LAN,
клиентский подключается по TCP на localhost. Игровые имена в обоих JAR переводятся
из SRG в MCP только для соответствия среде разработки; серверная реализация
берётся из опубликованного полного JAR, а не из заменителей или заглушек.
Для локального теста авторизация LAN-сервера отключена; внешние аккаунты не нужны.

Проверяются отсутствие серверных классов, рукопожатие и полный снимок, выполнение
квеста, серверная выдача хлеба и синхронизация инвентаря, дельта редактирования,
NBT и прогресс окна устройства, слоты обычного хранилища. Результат записывается
в `build/client-smoke/PASS.txt`; журналы — `host.log` и `client.log` рядом.
Тест не заявляет проверку всего пользовательского модпака одновременно.

Проверка тихого отключения в одиночной игре:

```sh
mc-gradle -p quests1710 clientSingleplayerSmokeJar
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=true LP_NUM_THREADS=2 ALSOFT_DRIVERS=null \
  python3 quests1710/tools/run_client_only_smoke.py --singleplayer
```

Проверяется обычное меню выбора миров, загрузка встроенного мира, отсутствие
книги и сетевых квестовых запросов без предупреждающего окна.
